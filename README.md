\# Vendor Performance Analysis



\## Project Overview



This project analyzes vendor sales and purchasing data to evaluate vendor performance, identify sales and profitability trends, and generate actionable business insights.



The project includes data ingestion, data cleaning, exploratory data analysis, vendor-level analysis, and an interactive Power BI dashboard.



\## Objectives



\- Analyze vendor sales performance

\- Identify high and low-performing vendors

\- Analyze purchasing and sales patterns

\- Evaluate vendor contribution to overall business performance

\- Generate meaningful business insights using data analysis and visualization



\## Tools \& Technologies



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- SQL

\- SQLite

\- Jupyter Notebook

\- Power BI

\- Git \& GitHub



\## Project Workflow



1\. Data ingestion

2\. Data cleaning and transformation

3\. Exploratory Data Analysis (EDA)

4\. SQL-based analysis

5\. Vendor performance analysis

6\. Creation of cleaned vendor sales summary

7\. Power BI dashboard development



\## Project Files



\- `Exploratory Data Analysis.ipynb` - Exploratory analysis and visualizations

\- `Vendor Performance Analysis.ipynb` - Vendor-level performance analysis

\- `get\_vendor\_summary.py` - Generates vendor summary data

\- `ingestion\_db.py` - Handles data ingestion into the database

\- `vendor\_sales\_summary.csv` - Cleaned and processed vendor sales summary

\- `powerbi/Vendor Performance Dashboard.pbix` - Interactive Power BI dashboard



\## Power BI Dashboard



The Power BI dashboard provides an interactive view of vendor performance, sales trends, purchasing patterns, and key business metrics.



\## Dataset



The original raw datasets are not included in this repository because of their large size.



The analysis was performed using the raw datasets, and the processed vendor sales summary is included in the repository.



\## Key Analysis Areas



\- Vendor sales performance

\- Sales and purchase trends

\- Vendor contribution analysis

\- Performance comparison between vendors

\- Business performance insights
